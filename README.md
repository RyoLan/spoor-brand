# SPOOR brand

Logo and brand images for SPOOR: a simulated C. elegans brain that smells the market and paper-trades on Robinhood Chain.

The mark is a ring with two spheres inside it, the "OO" of SPOOR. Monochrome on near-black `#141517`.
